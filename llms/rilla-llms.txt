# Rilla

> Rilla is an AI conversation-intelligence and coaching platform for in-person and outside
> sales and service teams. Reps record face-to-face customer conversations on the Rilla
> mobile app; Rilla transcribes and analyzes them so managers can run "virtual ridealongs"
> and coach at scale. Rilla publishes no public developer API, documentation portal, SDK or
> machine-readable specification. This file is generated by API Evangelist from the public
> record and from live probes — it is not published by Rilla.

## Products

- [Virtual Ridealongs](https://www.rilla.com/products/virtual-ridealongs): recorded, transcribed and analyzed field conversations managers review asynchronously
- [Rilla Intelligence](https://www.rilla.com/products/rilla-intelligence): analytics across thousands of in-person conversations
- [Rilla Live](https://www.rilla.com/products/rilla-live): live conversation support
- [Copilot](https://www.rilla.com/copilot): AI assistant surface
- [Roleplay](https://www.rilla.com/roleplay): AI roleplay practice for reps
- [Surveys](https://www.rilla.com/surveys): post-appointment survey capture

## API surface (no public contract)

- Production API host: `https://api.rillavoice.com/api/v1/` — every path returns HTTP 401 `Invalid Token`. This is the private backend of the Rilla web and mobile apps; no OpenAPI, Swagger, GraphQL SDL, AsyncAPI or Postman collection is published for it.
- Webhook receiver: `https://api.apirilla.com/webhooks/spotio` — an AWS API Gateway endpoint documented by the partner, [SPOTIO](https://support.spotio.com/hc/en-us/articles/14530983742743-SPOTIO-Rilla-Voice), as the callback URL for SPOTIO "Activity Created" events. Rilla does not document it on its own site.
- CRM integrations (Salesforce, HubSpot, Zoho, Pipedrive, Microsoft Dynamics, ServiceTitan and others) are delivered through the [Merge](https://www.merge.dev/case-studies/rilla) unified API, which Rilla consumes as a customer rather than exposes as a contract.
- No MCP server, no A2A agent card, no llms.txt is served by Rilla; `https://www.rilla.com/llms.txt` returns HTTP 404.
